# Aurora

Учебный проект на C++20 о движении электронов в магнитном поле и моделировании полярного сияния.

Сейчас работает первый пример: электрон движется по винтовой траектории в однородном магнитном поле. Координаты и импульс рассчитываются релятивистским методом Бориса.

## Запуск

В CLion откройте проект, выберите цель **Aurora** и нажмите **Run**. Аргументы не нужны.

Или из терминала в папке проекта:

```sh
cmake -S . -B build
cmake --build build --target Aurora
./build/Aurora
```

Нужны CMake 3.20+ и компилятор C++20. Скачивать дополнительные библиотеки не требуется.

Программа выводит параметры электрона, гиропериод, ларморовский радиус и отклонение энергии. Траектория сохраняется в `results/trajectory.csv` относительно рабочей папки. Полный путь выводится в консоль. При повторном запуске CSV перезаписывается.

## Изменение примера

Откройте [main.cpp](main.cpp). В начале `main()` находятся пять параметров:

```cpp
const double energy_keV = 10.0;
const double pitch_deg = 60.0;
const double magnetic_field_T = 3e-5;
const std::size_t periods = 10;
const std::size_t steps_per_period = 200;
```

Измените значение и запустите программу снова. Поле направлено вдоль `+z`; для этого примера задавайте положительное поле, питч-угол от 0 до 180 градусов и ненулевое число шагов на период.

Основной код примера — в `main.cpp`, физика и интегратор — в `include/aurora/` и `src/`.
