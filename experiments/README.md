# Физические эксперименты

Готовые отчёты: [индекс с графиками](results/reports/README.md). Для каждого
**реализованного** опыта там есть отдельный Markdown-файл: физический вопрос,
постановка, картинка, численный результат, вывод и ограничения. Сырые CSV
сохранены рядом, чтобы любой график можно было проверить.

Как пересчитать результаты и отчёты — в
[`src/experiments/README.md`](../src/experiments/README.md). После изменения
модели сначала пересчитываются CSV, затем запускается генератор отчётов.
Отчёты для ещё не реализованных этапов не создаются заранее.
